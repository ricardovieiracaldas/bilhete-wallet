Bilhete Wallet - protótipo experimental

1. Colocar os ficheiros num alojamento HTTPS gratuito (por exemplo, GitHub Pages).
2. Abrir o endereço no Safari do iPhone.
3. Selecionar o PDF Rede Expressos.
4. Confirmar os dados e guardar/partilhar a imagem.

Limitações: requer internet para carregar PDF.js; a extração foi criada para o layout do PDF de exemplo e não é garantida noutros bilhetes. O QR é copiado como imagem da primeira página, não reconstruído. Não cria um .pkpass assinado nem instala diretamente na Wallet. A opção da Apple de criar um cartão a partir de imagem pode não reconhecer os campos. Para partilha direta do PDF pelo menu do iOS seria necessária integração adicional, por exemplo um Atalho que envie o PDF para um endpoint ou app nativa.
